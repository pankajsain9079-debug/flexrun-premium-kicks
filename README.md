# FlexRun E-Commerce Experience

Create a premium e-commerce shoe brand website named FlexRun. Brand tagline: 'Run Beyond Limits'. Use a modern black, white, and electric blue color scheme. Design a professional logo featuring a sleek stylized F icon and FlexRun text. Include a stunning homepage hero section, featured products, running shoes, gym shoes, casual sneakers, best sellers, new arrivals, testimonials, about section, contact page, shopping cart, wishlist, product pages, and checkout flow. Make it fully mobile responsive with smooth animations, premium typography, search and filtering, and sample shoe inventory. The overall look should feel like a high-end athletic footwear brand competing with major sportswear companies.
